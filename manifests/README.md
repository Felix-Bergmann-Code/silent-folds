# Manifests

Generated by `warpaudit audit-data` and `warpaudit plan-study`. Pair, identity,
fold, and provenance artifacts must be reviewed before G1. No zero-row
placeholder manifests are committed.

`data.json` contains the complete image and annotation inventories (relative
paths, original dimensions, SHA-256 digests, archive provenance, and duplicate
audit). `pairs.parquet` records canonical direction, eye/patient evidence,
annotation files and hashes, grouping basis, and development assignment.
